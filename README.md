# 姜胡说笔记库

这个文件夹就是你的「笔记大脑」。三件套在这里打通：

| 工具 | 在这里的角色 | 怎么接入 |
|---|---|---|
| **Obsidian** | 打开这个文件夹当仓库，看笔记、双链跳转 | 打开 Obsidian → 「打开文件夹作为仓库」→ 选 `D:\姜胡说笔记` |
| **WorkBuddy** | 直接读写这里的 .md 文件，帮你写笔记、出脚本、批量整理 | 跟我说一句「读一下 D:\姜胡说笔记」就行，不需要任何配置 |
| **GitHub** | 云端备份，换电脑不丢 | 装 GitHub 连接器，或让我用 git 命令推送 |

## 文件夹怎么用

- `00-素材与想法` —— 随手记的灵感、看到的好句子、评论区问题
- `01-读书笔记` —— 一本书一个笔记文件，文件名就是书名
- `02-选题与脚本` —— 每条视频的选题和四段式脚本
- `03-成品文案` —— 已发布的视频文案、封面标题存档

## 三个规矩

1. **一本书一个文件**，文件名只用书名，不要加日期
2. **提到别的书就用双链**：输入 `[[书名]]`，两本书就自动连起来
3. **想到什么立刻写**，不要整理，整理交给 WorkBuddy

## 常用话术（直接跟我说）

- 「读一下我的读书笔记，挑 10 本能凑成一个书单的」
- 「按《认知觉醒》的笔记写 3 条视频脚本」
- 「把这周的笔记备份到 GitHub」
- 「把 01-读书笔记 里的内容整理成一份小报童专栏大纲」
