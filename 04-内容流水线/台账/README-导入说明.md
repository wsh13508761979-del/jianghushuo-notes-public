# 台账层 · 导入与使用说明

> 三份 CSV 已生成，可直接导入腾讯文档或飞书表格，四个账号共用一套表。
> 编码：UTF-8（带 BOM），中文不会乱码。

## 一、三份表各管什么

| 文件 | 管什么 | 谁填 | 什么时候填 |
|---|---|---|---|
| `01-选题库.csv` | 母题、账号角度、目标搜索词、钩子、计划日期 | 我（跑流水线时自动生成行） | 每周日排下一周 |
| `02-拆解卡.csv` | 对标视频的数据与结构拆解 | 我（看到好视频就拆） | 随时 |
| `03-发布记录.csv` | 每条片子的发布与 7 天数据 | 你（发完填一行） | 每次发完＋7 天后补数 |

## 二、导入腾讯文档（推荐，手机可看可改）

1. 电脑打开 **docs.qq.com**，登录同一个微信/QQ 账号；
2. 首页「新建」→「在线表格」→ 右上角「导入」→ 选 `01-选题库.csv`；
3. 重复导入另外两份，建议放在同一个文件夹「姜胡说·内容台账」；
4. 手机微信里打开腾讯文档小程序即可查看、勾选状态。

> 飞书同理：飞书云文档 → 新建多维表格 → 导入 CSV。二选一即可，不要两边都维护。

## 三、导入后必做的三件事

1. **冻结首行**（视图 → 冻结首行），滚动时表头不跑；
2. **加一列下拉选项**：选题库「状态」列设为 待拍/已拍/已发/废弃；发布记录「发布状态」设为 待发/已发/违规下架；
3. **删掉示例行**（A001-B003 是样例，留着会混）。

## 四、字段口径（避免以后对不上）

| 字段 | 口径 |
|---|---|
| 播放(7天) | 发布后第 7 天同一时间截图记录，不取峰值 |
| 点赞 | 同一天记录，不要和播放分两次取 |
| 涨粉 | 创作服务平台「粉丝分析」里该条带来的新增，估不出来就填 0 |
| 时长 | 成片实际时长，写「65秒」不写「1分05」 |
| 备注 | 只写三类：批次号、是否挂车、异常（如违规提示） |

## 五、和另外两层怎么接

```
流程层（WorkBuddy 技能「抖店四步短视频流水线」）
   ↓ 输出选题卡 → 直接粘进 01-选题库
   ↓ 输出脚本/成片指令 → 拿去拍、拿去剪
   ↓ 输出发布包台账行 → 粘进 03-发布记录
成片层（手机剪映）
   ↓ 导出成片 → 发布 → 回填 03-发布记录
```

一句话：**技能负责生产，表格负责记忆，剪映负责出片。** 表格里没有的记录，等于没做。
